# Results Directory

This directory stores outputs generated by training, evaluation, and inference runs.

## Folder Organization

- `graphs/`: Training loss/accuracy curves, confusion matrices, and model performance visualizations.
- `predictions/`: Batch prediction outputs, detection logs, and exported classification summaries.

> [!NOTE]
> All generated artifacts inside `graphs/` and `predictions/` are excluded by `.gitignore` to prevent repository clutter, while `.gitkeep` ensures the directory skeleton remains tracked in Git.
