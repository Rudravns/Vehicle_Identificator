# Test Assets Directory (`test/`)

> [!NOTE]
> This folder contains sample test fixtures, input imagery, and cropped detection output files used for manual pipeline verification and demonstration.
> For automated unit tests, see the [`tests/`](../tests/README.md) directory instead.

## Directory Contents

- `test_image.png`: The default sample image processed by the vehicle detection pipeline.
- `output_image.png`: Detection visualization generated by `visualizer.draw_rects()`, showing vehicle bounding boxes with confidence scores.
- `cropped_car_*.png`: Cropped vehicle patches generated from detections in `test_image.png`.
  - `cropped_car_7.png` is used by `src/main.py` as a sample vehicle crop for testing color classification inference.

## How It Is Used

- `src/loader.py`: `get_test_image_path("test/test_image.png")` resolves this folder's sample input.
- `src/visualizer.py`: Saves annotated drawings and cropped vehicle patches into this folder adjacent to the source image.
- `src/main.py`: Demonstrates color classification using `test/cropped_car_7.png`.
